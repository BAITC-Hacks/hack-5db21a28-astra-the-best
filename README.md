# Аким на 5 часов

Учебный симулятор решений для Астаны. У всех игроков одинаковые исходные показатели пяти игровых зон и бюджет 100 единиц. Выберите ровно пять мероприятий и посмотрите, как меняется Astana Quality of Life Score. **Показатели и эффекты синтетические: результат не является прогнозом реальной городской политики.** Горизонт — восемь условных кварталов. «5 часов» в названии задания означает время работы над кейсом, игрового таймера нет.

## Возможности

В интерфейсе бюджет показан как **10 млрд ₸**: **1 исходная единица = 100 млн ₸**. Это условные ассигнования на пакет или этап работ, а не реальные сметы. В API и расчётной модели сохраняются исходные 100 единиц и цены из ТЗ. Масштаб и назначение всех сумм описаны в [docs/BUDGET.md](docs/BUDGET.md).

- Карта всей Астаны на MapLibre и OpenFreeMap: объёмные здания, пять игровых зон, выбор зоны, слои исходных показателей и 14 видов знаков мероприятий. Знаки показывают черновик, план и эффект после расчёта; их точки иллюстративны.
- При первом входе — приветствие и обучение по реальным действиям: район, план, расчёт и разбор отчёта. Его можно пропустить или снова открыть кнопкой «Обучение».
- Навигация переключает «Город» и «Отчёт» в центре верхней панели; интерфейс оформлен в графитово-серебристой палитре.
- Редактор с пятью слотами, выпадающими списками направления и района, стоимостью, лагом и ожидаемыми плюсами и минусами. Замена, удаление и причины недопустимого выбора видны сразу.
- Серверная проверка и детерминированный расчёт. Отчёт показывает Score, все 50 показателей до и после, слабейший район, критические значения, эффекты и синергии.
- AI-анализ с сильными сторонами, рисками, последствиями и советом при настроенном серверном ключе. Расчёт доступен и без AI; ошибка анализа не удаляет числа.
- В отчёте можно сохранить до шести сценариев в этом браузере, сравнить пересчитанные показатели и найти проверяемое улучшение заменой одной меры или её района. Поиск не обещает глобальный оптимум и не вызывает AI.
- Текущий отчёт можно скачать как автономный HTML для печати в PDF или как JSON с точными числами. Экспорт сверяет результат с текущей моделью; AI-текст включается лишь при совпадении сценария и фактов.
- На карте есть включаемое декоративное движение: до 16 точек на видимых дорогах при приближении. Оно не участвует в расчёте и останавливается при перемещении карты, скрытой вкладке или настройке уменьшения анимации.

## Установка и запуск

Нужны Node.js `>=22.14.0 <23`, npm `>=10 <11`, интернет для подложки карты и браузер с WebGL. Проверенная среда разработки — Windows и PowerShell. Из корня репозитория:

```powershell
npm.cmd ci
Copy-Item .env.example .env.local
npm.cmd run dev
```

Откройте [http://127.0.0.1:3000/](http://127.0.0.1:3000/). Ключ для расчёта не требуется. Для AI-анализа впишите действующий `AI_API_KEY` в **неотслеживаемый** `.env.local` и перезапустите сервер. `AI_BASE_URL` по умолчанию указывает на совместимый с OpenAI API, `AI_MODEL` — `gpt-6-luna` (без reasoning, до 2500 токенов ответа). Провайдер и модель возвращаются вместе с анализом. Ключ не передаётся клиенту.

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run build
npm.cmd run start
```

Для браузерных тестов нужен установленный **Google Chrome**: сценарии явно используют Playwright `channel: 'chrome'`. Установка только bundled Chromium через `playwright install chromium` для этих тестов недостаточна. Запуск: `npm.cmd run test:e2e -- --reporter=line --workers=2`.

## Контрольный пример

При первом входе нажмите **«Освоюсь самостоятельно»**, чтобы выполнить пример без подсказок. В режиме «Город» откройте **«План · 0/5»**. Для районных мер сначала выберите район, затем добавьте меру:

| Мера | Район | Стоимость в ТЗ, ед. | В интерфейсе |
|---|---|---:|---:|
| M7 — Школа и детсад | Нура | 24 | 2,4 млрд ₸ |
| M8 — Поликлиника | Нура | 20 | 2 млрд ₸ |
| M10 — Освещение и камеры | Нура | 12 | 1,2 млрд ₸ |
| M12 — Платформа обращений | Весь город | 14 | 1,4 млрд ₸ |
| M5 — Чистое топливо | Сарыарка | 25 | 2,5 млрд ₸ |

Стоимость — **95 ед. = 9,5 млрд ₸**, остаток — **5 ед. = 500 млн ₸**. После **«Рассчитать сценарий»** исходный Score **52,55768**, итоговый **56,54307**, изменение **+3,98539**. Интерфейс показывает два знака после запятой, API сохраняет полную точность. Синергия M10 + M12 добавляет показатель безопасности улиц в Нуре. Короткий сценарий показа — [docs/DEMO.md](docs/DEMO.md).

После расчёта откройте в отчёте **«Сравните свои решения»**: назовите вариант и нажмите **«Сохранить текущий сценарий»**. Затем измените один пункт плана, рассчитайте его заново и сравните Score, бюджет и критические показатели. Кнопка **«Найти проверяемое улучшение»** перебирает допустимые изменения ровно одного решения; предложенный вариант можно перенести в план и пересчитать. Сохранения находятся только в браузере, где были созданы. Кнопки **«Скачать отчёт · HTML / PDF»** и **«Скачать данные · JSON»** выгружают текущий проверенный расчёт; для PDF откройте HTML и выберите печать → «Сохранить как PDF».

## Правила и данные

Использованы подробные правила источника S2: ровно пять уникальных мер, максимум две меры одного направления, бюджет не выше 100, район обязателен только для районной меры. Поэтому достаточно минимум трёх направлений; выбирать по одной мере каждого направления не требуется. Расхождение с краткой формулировкой S1 и вопрос организаторам записаны в [docs/DECISIONS.md](docs/DECISIONS.md).

Эффект меры с лагом `L` учитывается с долей `(8−L)/8`. После фиксированных синергий каждый показатель ограничивается диапазоном 0–100. Score = `0,7 × средневзвешенный балл районов + 0,3 × балл слабейшего района − число показателей ниже 40`. Сервер сам проверяет решения и считает цену; клиент не передаёт готовый Score. HTTP-контракт — [docs/API.md](docs/API.md).

Числа перенесены из [снимков задания S1–S3](docs/sources/README.md). География основана на OpenStreetMap, подложка — OpenFreeMap. Преобразование шести современных районов в пять **игровых**, атрибуция и лицензии описаны в [docs/MAP_SOURCES.md](docs/MAP_SOURCES.md). Игровые зоны нельзя трактовать как официальное деление или реальные районные измерения.

Стек: Next.js 16, React 19, TypeScript, MapLibre GL JS, Zod, Vitest, Playwright. `src/data` хранит канонические данные; `src/domain` валидирует и считает; `src/app/api` предоставляет сценарий, расчёт и анализ; `src/features` содержит карту, редактор, эффекты и отчёт. Сервер пересчитывает сценарий перед AI-запросом: модель объясняет факты и не заменяет математику.

Без `AI_API_KEY` запрос анализа явно сообщает об отсутствии настройки; подставного текста нет. Контрольный живой `POST /api/analyze` с `gpt-6-luna` вернул HTTP 200 и структурированный отчёт с валидными ссылками на рассчитанные факты; используется `reasoning_effort: none`. Публичный URL приложения будет указан только после проверенного развёртывания.
