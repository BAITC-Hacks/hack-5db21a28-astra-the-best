Общий прогон после адаптивных исправлений и замены списков P16: `npm.cmd run test:e2e -- --reporter=line --workers=2` — **21/21 passed** (49,7 с), включая 30-секундный маршрут, отказ WebGL и шесть проверок компоновки/фокуса на трёх размерах. `npm.cmd test -- --run tests/ui/planner.test.tsx` — **4/4 passed**, `npm.cmd run typecheck` — без ошибок. Bundled Chromium Playwright не скачался из CDN по тайм-ауту, поэтому тесты запускают установленный Google Chrome (`test.use({ channel: 'chrome' })`).

Условия замера: Windows 11 Pro, ноутбук 911XWildHunterG2Pro, Intel Core i5-12450H, 31,7 ГБ RAM, Intel UHD + NVIDIA RTX 4060 Laptop, Google Chrome 153.0.8010.53, Ethernet-адаптер 1 Gbps; фактическая пропускная способность внешней сети не измерялась. Время загрузки и реакции получено в headless Playwright: новый browser context очищает его кеш, но кеш CDN/ОС мог быть тёплым. FPS измерен отдельно в открытом Chrome kiosk через PresentMon на Intel UHD. На старте `innerWidth×innerHeight` = 1920×1080, в конце 1920×1079 (вариация высоты 1 px); вкладка оставалась visible/focused. CSV содержит 1684 записи выбранного swapchain, из них 1678 с валидным временем смены кадра. `TimeInMs` выбранного swapchain охватывает 0,912–26,367 с записи; при расчёте 30 интервалов остальные секунды учитывались нулями, то есть медиана 54,5 не завышена отсутствующими кадрами. Ранее полученные 163,9 callbacks/s `requestAnimationFrame` в headless Chrome были лишь прокси и не использованы как FPS.

Главный браузерный путь повторён на текущем рабочем дереве после P16. Финальная проверка коммита и сдача относятся к P12.
