# Размещение на Vercel

Проверка совместимости: 23 сентября 2026. Приложение использует поддерживаемый Vercel Next.js App Router и серверные Route Handlers. Отдельные база данных и постоянно работающий backend не требуются. Это оценка совместимости по коду; успешный удалённый deployment пока не подтверждён.

## Настройки проекта

1. Импортировать итоговую версию репозитория команды; корень проекта — корень репозитория.
2. Framework Preset: **Next.js**, Node.js: **22.x** (соответствует `package.json`). Install Command: `npm ci`. Build Command: `npm run build`. Output Directory оставить стандартной для Next.js. Не выбирать статический export: он не предоставляет API расчёта и анализа.
3. В Environment Variables добавить серверные переменные для нужного окружения Preview/Production:

| Переменная | Значение |
|---|---|
| `AI_API_KEY` | Действующий ключ провайдера; вводить только в настройках Vercel, не в Git и не с префиксом `NEXT_PUBLIC_` |
| `AI_BASE_URL` | `https://api.openai.com/v1` |
| `AI_MODEL` | `gpt-6-sol` |
| `AI_TIMEOUT_MS` | `30000` |
| `AI_MAX_REQUESTS_PER_MINUTE` | `10` |

4. Создать deployment после настройки переменных. При изменении переменных создать новый deployment.
5. На полученном URL повторить [контрольный сценарий README](../README.md) и [демонстрацию для жюри](JURY_DEMO.md): карта, выбор пяти мер, Score `56.54307`, живой AI-анализ, поиск оптимума, скачивание HTML/JSON.

## Что требуется для работы

- Без ключа расчёт, оптимизатор, сравнение и экспорт работают; AI возвращает явное сообщение об отсутствии настройки.
- Для карты нужен браузер с WebGL и доступ к внешним тайлам OpenFreeMap. Ключ карт не требуется.
- Сохранённые сценарии находятся в localStorage браузера. При переходе с localhost на домен Vercel старые локальные сохранения автоматически не переносятся.
- Ограничитель AI-запросов и кеш оптимума находятся в памяти экземпляра сервера. На Vercel они не являются общим хранилищем всех экземпляров и могут сбрасываться при холодном старте. Для публичной нагрузки нужен общий лимитер либо правила Vercel Firewall; текущий ограничитель не гарантирует общий лимит расходов.
- Общий timeout AI включает одну попытку исправления содержимого ответа. Лимит времени Vercel Function должен позволять закончить этот запрос; проверьте фактические настройки проекта.

На момент проверки локальная папка не связана через `.vercel/project.json`, Vercel CLI не обнаружен, проверенный публичный URL не предоставлен. Этот документ не утверждает, что приложение опубликовано.
